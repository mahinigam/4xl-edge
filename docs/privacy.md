# Privacy Center

4XL Edge is built as a **Privacy-First** application. 

## Local First Processing
By default, 4XL Edge attempts to process all images entirely on-device, whether through a native Snapdragon NPU, a discrete GPU, or within the browser using WebGPU. During local inference, the source image never leaves your machine.

## Cloud Mode Transparency
If cloud mode is required or explicitly chosen, 4XL Edge provides clear indicators. The backend server suppresses logging of uploaded images and purges them aggressively to maintain privacy.
