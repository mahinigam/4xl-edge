# 4XL Edge Deployment

## Overview
This repository manages two main distribution targets:
1. **Public Web Demo**: Hosted on Hugging Face Spaces (React + Server Backend + WebGPU).
2. **Native Snapdragon App**: A Windows App SDK (WinUI 3) package for ARM64 PCs.

## CI/CD
GitHub Actions handle testing, linting, Python validations, and the compilation of the native Windows ARM64 application.
